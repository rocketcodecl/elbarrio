El Barrio

Política de privacidad

Última actualización: 11 de agosto de 2026

1. Información que utilizamos

El Barrio utiliza nombre, apellidos, correo electrónico, teléfono opcional y RUT para crear, proteger y verificar la cuenta. La dirección, comuna y ubicación GPS se usan para confirmar pertenencia territorial y ofrecer contenido cercano. El RUT, la dirección exacta y la ubicación precisa no se muestran públicamente a otros vecinos.

2. Contenido y actividad comunitaria

Tratamos las publicaciones, fotografías, comentarios, opiniones, alertas, invitaciones, favoritos, acuerdos y mensajes privados necesarios para prestar las funciones solicitadas. El contenido que decides publicar puede ser visible para otros usuarios del barrio.

3. Finalidades

  • Crear, autenticar y proteger cuentas.
  • Verificar residencia y entregar contenido territorial.
  • Operar Mercado, Servicios, Comercios, Eventos, Alertas, mapas y mensajería.
  • Enviar notificaciones solicitadas.
  • Prevenir fraude, abuso y contenido prohibido.
  • Atender consultas y solicitudes de soporte.

4. Permisos del dispositivo

La cámara y galería se usan cuando eliges tomar o adjuntar imágenes. La ubicación se solicita para verificar el barrio y usar funciones cartográficas. Las notificaciones requieren autorización del dispositivo. Puedes administrar estos permisos desde Android.

5. Proveedores y seguridad

El Barrio utiliza proveedores de infraestructura como Supabase para base de datos, autenticación y almacenamiento; Google para inicio de sesión; Firebase para notificaciones push; y proveedores de análisis automatizado cuando el usuario solicita funciones de inteligencia artificial o cuando corresponde moderar contenido público. No vendemos información personal. Los datos se transmiten mediante conexiones cifradas.

6. Moderación

El contenido público puede analizarse automáticamente o revisarse administrativamente para detectar fraude, amenazas, acoso, actividad ilegal o exposición de información personal. Los mensajes privados no se envían al sistema de moderación de contenido público.

7. Eliminación y conservación

Puedes eliminar tu cuenta desde Perfil → Privacidad y seguridad → Eliminar mi cuenta. También puedes solicitarla externamente en la página indicada abajo. Al eliminarla se revoca el acceso y se anonimizan datos identificatorios como RUT, dirección, GPS, correo, teléfono y avatar. Algunas publicaciones, mensajes y registros mínimos de seguridad pueden conservarse anonimizados para preservar conversaciones, prevenir abuso o cumplir obligaciones aplicables.
